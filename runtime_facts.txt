This exhibition prototype is a real NVIDIA Jetson Orin Nano computer (8 GB) inside the bag. Everything runs on the device itself with no cloud connection: an IMX219 camera, a YOLO object detector that spots tools held up to the camera so KOMA can respond to them, a small Gemma vision-language model of about two billion parameters, offline Vosk listening for the wake word "Koma", offline Whisper speech recognition turning the visitor's question into text, and a Piper text-to-speech voice through a Jabra speakerphone.
Camera frames and audio are processed in memory and are not recorded or saved. KOMA remembers only the last three exchanges of the current conversation in memory, and forgets them when a new visitor session starts or the program stops.
Q4 is not connected to this prototype, so there are no live sensor or exposure readings. There is no protective mode that monitors safety; KOMA cannot certify that anything is safe.
To speak to KOMA, the visitor starts a sentence with "Koma". Saying "hey Koma" interrupts KOMA while it is talking. A fresh session starts when a visitor scans the TradesMaster ID card. There is no on-device button to switch sensing off; the operator can stop the program.
