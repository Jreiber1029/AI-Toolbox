This exhibition prototype is a real NVIDIA Jetson Orin Nano computer inside the bag. Everything runs on the device itself with no cloud connection: an IMX219 camera, a YOLO object detector trained to recognise tools and protective equipment, a small Qwen vision-language model, offline Vosk speech recognition listening for the wake phrase "Hey KOMA", and a Piper text-to-speech voice through a Jabra speakerphone.
Camera frames and audio are processed in memory and are not recorded or saved. KOMA remembers only the last few exchanges of the current conversation in memory, and forgets them when a new visitor session starts or the program stops.
PPES is not connected to this prototype, so there are no live sensor or exposure readings. There is no protective mode that monitors safety; KOMA cannot certify that anything is safe.
The visitor can say "Hey KOMA, new visitor" to start a fresh session. There is no on-device button to switch sensing off; the operator can stop the program.
